# Platform map

Campusverse is nine systems on one Campus Core, with Verse AI across all of them (rule book §12–13,
docs/rulebook/). Schools, colleges, universities and groups use the same platform; each institution's
profile switches modules on or off (§12.3). `apps/web/lib/systems.ts` is the code version of this
page: the sidebar shows live modules from it and `/apps` shows every module. Change both together.

Status: **Live** is built and tested. **Being built** has started. **Planned** is in the rule book
but not started; build it in the §17 roadmap order.
