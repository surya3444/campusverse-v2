# 0004 Design system choices

Date: 2026-11-04 · Status: accepted, pending your review of the Day Line

| Topic           | Decision                                                                                                                                                                                        | Why                                                                                                                                                         |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Logo navy       | Logo files keep their own navy `#053495`; the interface uses the guide's `navy-950` `#04266D`                                                                                                   | The logo is used exactly as supplied. The two navies look alike side by side                                                                                |
| Logo files      | Four kept in `packages/ui/assets/brand`: colour logo, white logo, colour icon, white icon. The white logo and both icons are derived from the colour logo's paths, so the geometry is identical | The supplied set had a duplicate white logo and an all-navy variant we don't need                                                                           |
| Extra tokens    | `ink-muted` `#45536F`, `line`, signal tints, bright signals for the navy Day Line, and `signal-go-strong` `#08704A`                                                                             | The guide's `signal-go` gives 4.4:1 with white text, below AA for small text. `-strong` is used wherever green carries text, such as the Development banner |
| Palette         | Tailwind's default colours are switched off; only Campus Verse tokens exist                                                                                                                     | Ad-hoc colours can't creep in                                                                                                                               |
| Focus           | A navy ring plus a cyan halo, everywhere                                                                                                                                                        | Visible on both paper and navy                                                                                                                              |
| Fonts           | Plus Jakarta Sans, with Noto Kannada, Telugu, Tamil and Devanagari falling back per character (loaded on demand)                                                                                | Mixed-script text renders in one font stack                                                                                                                 |
| Urdu            | Right-to-left via `:lang(ur)`; device font for now                                                                                                                                              | A Nastaliq face needs choosing with an Urdu-reading reviewer                                                                                                |
| Command palette | `cmdk` (built on Radix) for the Verse Bar                                                                                                                                                       | Accessible combobox behaviour without writing it ourselves                                                                                                  |
| Data Grid       | TanStack Table v9 for the row and column model; our own keyboard and paste handling                                                                                                             | Excel-like entry is the product; the library has no editing model                                                                                           |
| Review aids     | `/?state=…&at=HH:MM` shows any Day Line state at a pinned time; `/design` shows every component and state                                                                                       | Lets you and real staff review without data                                                                                                                 |
