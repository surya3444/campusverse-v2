# 0006 Design revision: calm, enterprise-grade

Date: 2026-11-04 · Status: accepted · Supersedes parts of 0004 and the Build Guide's UI section

Your review of Milestone 6: the font wasn't right, the dashboard wasn't good, the bottom bar was irritating. You want an enterprise-grade, visually soothing look.

| Topic          | Before                                                                   | Now                                                                                                                                                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fonts          | Plus Jakarta Sans everywhere                                             | As on campusverse.app: **Instrument Sans** for text, **Plus Jakarta Sans** for headings (tracking -0.02em). Noto fallbacks unchanged                                                                                                                                      |
| Surfaces       | Navy bands, 2px navy borders, dashed panels                              | Light paper background, white panels with 1px hairline borders, 12px radius. Navy only for the main action, the active item and the now line                                                                                                                              |
| Elevation      | None                                                                     | A soft shadow on overlays only (menus, drawers, dialogs, palette). Surfaces stay flat                                                                                                                                                                                     |
| Status colours | Bright fills                                                             | Soft tints with dark text; solid colour only for stripes and dots                                                                                                                                                                                                         |
| Home           | Big greeting, navy Day Line band, one summary sentence, stacked worklist | Title and date; one key-figures strip (four numbers in one panel, not separate cards); the Day Line as a light, lane-based schedule (Transport, Attendance, Classes, Assessment, Gate, plus Alerts); "Needs attention" beside it on very wide screens, below it otherwise |
| Verse Bar      | Fixed command line at the bottom of every screen                         | Removed. A search field in the header opens a centred **command palette** (Ctrl K / ⌘K); a search icon on phones. Find, Do and Ask Verse AI are unchanged, and AI answers stay labelled                                                                                   |
| Shell          | Logo and nav                                                             | Sidebar with school switcher at the top, quieter nav, signed-in user at the bottom; slim header with search and notifications                                                                                                                                             |
| Preview Canvas | Full-screen navy header                                                  | Large dialog on a soft background, panels for each section, sticky footer; full screen on phones                                                                                                                                                                          |

Kept: the Day Line as the home's centre, the Preview Canvas for every bulk action, the Record Drawer, the Data Grid's behaviour, every view state, WCAG 2.1 AA (axe-checked on every page), and no off-the-shelf look.
