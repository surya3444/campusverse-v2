# 0012 Admissions and certificates

Date: 2026-11-05 · Status: accepted

| Topic                 | Decision                                                                                                                                                                                                                                           | Why                                                           |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Spec                  | `docs/specs/ADMISSIONS_CERTIFICATES.md`, drafted from the Schools Release spec before building; open questions carry defaults                                                                                                                      | The guide: no milestone without its spec                      |
| Modules               | `school/admissions` and `school/certificates` (school academic). They write other modules only through contract primitives in the caller's transaction: `createPerson`, `enrol`, `billStudent`, `endEnrolment`, `studentLeaves`, `issueDocumentIn` | One owner per table; one transaction per use case             |
| One-transaction issue | `platform/documents` gained `issueDocumentIn(tx, …)`; `issueDocument` wraps it. A TC numbers, freezes the PDF and closes the enrolment together                                                                                                    | No issued TC with an open enrolment, or the reverse           |
| Numbers               | `school_number_counter` per institution, kind and year, taken under a row lock: `2026-0001` for admissions, `TC/2026-27/0001` for certificates; never reused, even when a request is cancelled                                                     | Spec: no reused numbers                                       |
| Maker-checker         | TC: the class teacher checks, the principal approves, and the checker can't approve (code and a CHECK constraint)                                                                                                                                  | Spec TC flow                                                  |
| Fee disclosure        | No offer without a published fee plan for the class; the offer shows every head and instalment                                                                                                                                                     | Spec fee disclosure                                           |
| Mid-year joiners      | `billStudent` never bills instalments already due before the joining day                                                                                                                                                                           | Spec: fee prorates by policy (default: skip past instalments) |
| Seats                 | Held from the offer; a lapsed offer frees its seat and offers the next waitlisted applicant, checked when the pipeline is read                                                                                                                     | No scheduler needed for the pilot                             |
| Dues and TC           | Warning only up to Class 8; above, a school setting with default warning only                                                                                                                                                                      | Spec; legal advice before blocking                            |
| Public check          | `/verify/<code>` on the web, served from the API's public endpoint without a session; shows kind, number, version, date and status only                                                                                                            | Spec public verification page                                 |
| PDF script            | English only for now: pdf-lib can't shape Indic scripts                                                                                                                                                                                            | Regional PDFs need a shaping engine (HarfBuzz) later          |
| Rule packs            | `admissionAgeRule` (CBSE LKG and Class 1) and `tcDeadline` (Karnataka 7 days), unverified                                                                                                                                                          | Spec: age and timer come from rule packs                      |

**Known gaps:** see both module READMEs.
