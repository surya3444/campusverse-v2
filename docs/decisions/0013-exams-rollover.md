# 0013 Exams and year-end rollover

Date: 2026-11-05 · Status: accepted

| Topic                | Decision                                                                                                                                                                                                                                                              | Why                                                             |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| Spec                 | `docs/specs/EXAMS_ROLLOVER.md`, drafted before building; open questions carry defaults                                                                                                                                                                                | The guide: no milestone without its spec                        |
| Modules              | `school/exams` and `school/rollover` (school academic). Rollover writes enrolment and people through contract primitives (`setOutcome`, `enrolForRollover`, `undoRolloverEnrolments`, `continueMembership`, `studentLeaves`, `studentReturns`) in its own transaction | One owner per table; one transaction per use case               |
| Marks                | `numeric` in the database, hundredths (integers) in code; blank is never zero; codes AB, ML, UFM, EX, NA                                                                                                                                                              | Never float; spec code rules                                    |
| Lock and change      | After the lock a mark changes only by a request approved by someone else (code and a CHECK constraint)                                                                                                                                                                | Maker-checker                                                   |
| Grading              | `gradeScheme(board)` from `packages/rules`; the scheme id is frozen with each result                                                                                                                                                                                  | Old report cards keep their scale when the board changes it     |
| Report cards         | One PDF per student at publishing, through `issueDocumentIn`, numbered `RC/<year>/<exam>/<adm no>`                                                                                                                                                                    | Same QR check as certificates                                   |
| Promotion            | `promotionRule(board, class)`: promote up to Class 8; review below the pass mark in 9 and 11; board classes pass out                                                                                                                                                  | RTE no-detention; spec                                          |
| Results for rollover | The last published exam (default for open question 3)                                                                                                                                                                                                                 | Simple and explainable                                          |
| Unpublished exams    | A warning, not a block (default for open question 2)                                                                                                                                                                                                                  | A school can still close the year                               |
| Planner              | Pure function; gender round-robin by marks; never by caste, religion or similar                                                                                                                                                                                       | Spec: balanced sections, no sensitive factors                   |
| Undo                 | Allowed until the new year has attendance or invoices                                                                                                                                                                                                                 | After that, undo would orphan real records                      |
| Screens              | Marks are entered one subject and section per grid, with autosave; invalid cells stay local until fixed                                                                                                                                                               | A teacher enters one subject; a bad cell doesn't block the rest |

**Known gaps:** see both module READMEs.
