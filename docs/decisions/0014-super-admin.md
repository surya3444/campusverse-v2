# 0014 Super admin

Date: 2026-11-05 · Status: accepted

| Topic          | Decision                                                                                                                                                                                                              | Why                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Spec           | `docs/specs/SUPER_ADMIN.md`, drafted from the guide because the Admin Portal plan is not in the repository; open questions carry defaults                                                                             | The guide: no milestone without its spec                                 |
| Apps           | `apps/admin` (Next.js, port 3001) with its own httpOnly cookie; the API serves `/api/v1/admin/*` behind `StaffGuard`                                                                                                  | Guide: school app and super admin are separate apps                      |
| Sign-in        | Passkeys only, `@simplewebauthn` 13.3 (old enough for the release-age rule), user verification required; enrolment links; 30-minute idle, 8-hour sessions                                                             | Guide: passkeys and short sessions; don't invent cryptography. SSO later |
| Data           | Global schema `control`, allowlisted in the tenant-isolation suite like `identity` and `ops`                                                                                                                          | Admin records are not tenant data                                        |
| No bypass      | Admin work in a customer runs through `withTenant` with audit rows on both sides; cross-customer counts use `eachTenant` (one read-only transaction, tenant switched per customer). No SECURITY DEFINER, no BYPASSRLS | Guide: audited service functions, not a blanket tenant bypass            |
| Ports          | Students, deliveries, the support summary and signup come from their modules through ports wired by the API                                                                                                           | A module owns its tables                                                 |
| Enforcement    | ActorGuard checks customer status and `writes_off` on every school request; the worker checks `messaging_off`; finance checks the `online_payments` flag and `payments_off`                                           | One decision point per effect                                            |
| Maker-checker  | Status changes and support access need a second staff member (code and CHECK constraint). Switches are immediate, owner-only, with a reason                                                                           | Speed matters in an emergency (open question 2)                          |
| Support access | Read-only summary (setup, imports; counts and codes, no names), at most 4 hours, logged at the school each view                                                                                                       | Least privilege (open question 1)                                        |
| Plans          | Over the student limit is shown, never blocking                                                                                                                                                                       | Open question 3                                                          |
| Read-only mode | Refuses every non-GET school request, including previews sent as POST                                                                                                                                                 | Simple and safe; previews wait until the switch is off                   |

**Known gaps:** see `modules/platform/control/README.md`.
