# 0017 Invitation, onboarding and simulated providers

Date: 2026-11-06 · Status: accepted

| Topic              | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Why                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Account creation   | The super admin invites an organisation admin (name, phone, email, plan). The invite is a login by phone with no organisation yet (`ensureLogin`) plus `control.account_invite`                                                                                                                                                                                                                                                                                                       | The owner's request: the admin builds their own organisation                              |
| Sign-in            | Phone + OTP, as for everyone else                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Owner's choice; no passwords to store or reset                                            |
| Onboarding         | After sign-in, a login with no profile and an open invite goes to `/onboarding`: your profile, organisation, campuses, institutions, review. Drafts are saved on the invite. `completeOnboarding` (school/setup) creates the whole tree in one transaction: organisation, legal entity, campuses, institutions with their profiles, school roles, the admin (organisation-wide school administrator, designation, login link) and the customer on the invited plan                    | One step that either all happens or none does                                             |
| Institution types  | Schools only; colleges and universities are shown as "coming soon". Boards other than CBSE are "coming soon" (only CBSE has rule packs)                                                                                                                                                                                                                                                                                                                                               | First release is schools only                                                             |
| Profiles           | Campuses: address, city, district, state, PIN. Institutions: UDISE+, affiliation, year established, medium, classes, address, phone, email, website. Admin: name, designation, email                                                                                                                                                                                                                                                                                                  | What a school is asked for at sign-up                                                     |
| Simulation         | `SIMULATE_PROVIDERS`: on by default in development and test, off by default in live. When on, the OTP comes back to the screen that asked for it as a "simulated SMS", the invitation SMS shows in the admin portal, and notices and alerts are recorded as sent by `simulated-*` providers. A banner on every page says so                                                                                                                                                           | Owner's request; the switch keeps live safe by default                                    |
| Simulation in live | Allowed only by setting `simulate_providers = "on"` in the live Terraform variables                                                                                                                                                                                                                                                                                                                                                                                                   | Owner chose to allow it before real schools; it is a critical risk while on (RISKS.md C6) |
| Real data          | Signed in, every screen uses the institution chosen in the scope switcher (organisation · campus · institution, from the real tree). The home screen shows today's real figures (registers marked, present, collected, overdue), the Day Line shows when each register was marked, and Needs attention comes from setup readiness, attendance, fee approvals and certificates. Ctrl K searches real students. The synthetic school remains only on the signed-out design-review pages | No made-up data for real users                                                            |
| Storage            | Files use S3 (an S3 emulator locally); nothing is simulated there                                                                                                                                                                                                                                                                                                                                                                                                                     | S3 exists in every environment                                                            |

**Not yet:** adding campuses or institutions after onboarding (a settings page), colleges and universities, boards beyond CBSE, a simulated-message inbox screen (notices show per-channel status already).
