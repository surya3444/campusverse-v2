# 0019 Design 3.0

Date: 2026-11-06 · Status: accepted · Builds on 0018

The owner still found Design 2.0 basic and asked for an out-of-the-box, aesthetic product with illustrations, perfect alignment and any colours, as long as the primary is blue. The admissions pipeline was singled out.

| Topic         | Decision                                                                                                                                                                                                                                                                                                                                              | Why                                                        |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Primary       | Royal blue `#2150e0` (white on it 6.4:1). The `navy-*` token names are kept so every screen changed at once                                                                                                                                                                                                                                           | Owner: the primary should be blue; the old navy read black |
| Midnight      | `midnight-*` and the `midnight` surface (deep blue with soft blue and cyan light) for the sidebar of both apps, the home welcome card, the sign-in brand panel and the environment bar                                                                                                                                                                | A distinctive, premium frame that keeps content light      |
| Heroes        | Every page opens with a hero card (`PageHeader`): white washed with the area's tint, a dot grid, an eyebrow chip naming the section, a large title, the actions, and the area's illustration                                                                                                                                                          | Each area is recognisable at a glance                      |
| Illustrations | `Illustration` in packages/ui: original flat scenes as inline SVG drawn only with theme tokens (accents sun, coral, mint, lilac, skin tones exist only for artwork). Decorative and `aria-hidden`                                                                                                                                                     | Warmth without image files or a licence                    |
| Gradients     | Allowed only in the `hero` and `midnight` surfaces and the setup card's accent edge. Still none on buttons, text or data                                                                                                                                                                                                                              | Depth where it frames, never where it distracts            |
| Alignment     | One content column, 1240 px, shared by the top bar and every page; pages don't set their own width (except the receipt and the notice composer). One vertical rhythm: 24 px between blocks                                                                                                                                                            | Edges line up from the top bar down                        |
| Interaction   | `lift` on clickable cards (shadow and 1 px rise), the blue button glow `--shadow-button`, 16 px panel radius, 28 px hero radius                                                                                                                                                                                                                       | Feels responsive and soft                                  |
| Admissions    | A board, not a strip: "this year at a glance" funnel (new, applying, offered, confirmed, enrolled with shares), seat meters per class (amber at 85 %, red when full), coloured stage columns with counts and an empty-stage placeholder, cards with avatar, class, category, sibling, follow-up (red when overdue), offer end, source and last update | Owner: the pipeline was the worst screen                   |

**Sign-in.** Two earlier passes (floating example cards, then an orbit diagram with facts) read as generic and crowded. The brand side now holds only the Campus Verse mark drawn large and cropped in blue-to-cyan light, one headline ("One home for every campus.") and one line of campus types: schools live; colleges and universities coming soon. The form side holds only the form, how to get an account, and a footer. No made-up numbers.

**Not yet:** the parent and teacher mobile app keeps its own styling; detail pages use the new frame but not illustrations.
