# 0021 Verse AI first: actions you confirm, and names

Date: 2026-11-10 · Status: accepted · Changes 0015 (Writes, Data)

The owner asked for an AI-first interface "where everything can be handled by AI", and chose these three options.

| Topic     | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Why                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Writes    | Verse AI **prepares** actions; nothing changes until the person taps **Confirm**. A tool with risk `act` has a read-only `prepare` (shows exactly what will change) and an `execute` that calls the owning module's normal use case as that person: same `can()`, RLS, audit and outbox. The proposal is stored (`verse_action`), expires after 15 minutes, can be confirmed once, only by the person it was prepared for. Confirming re-checks the permission and writes `platform.verse.act` to the audit. | Owner's choice: "act, you confirm". The model never writes; a person does, through the same code paths |
| Data      | A new data class `names`: people's names, classes and admission or employee numbers may go to the model so it can find people and act. Phones, emails, Aadhaar-like numbers, addresses, health, marks and fees per person stay out; tool output is still scrubbed and fenced. `personal` and `sensitive` stay off                                                                                                                                                                                            | Owner's choice: "names only". Acting on "Omkar" needs the name; nothing more is needed to act          |
| Placement | Sign-in lands on the Verse AI home (`/ask`): one ask box, what needs the person now, suggestions for their role, and recent conversations. Every school page has a Verse AI panel that knows the page. The normal screens stay for detail                                                                                                                                                                                                                                                                    | Owner's choice: "AI home + side panel"                                                                 |
| Memory    | Follow-up questions see the conversation's last few questions and answers (same person, same conversation), nothing else                                                                                                                                                                                                                                                                                                                                                                                     | "Approve it" needs to know what "it" is                                                                |

**Before real schools use it:** the model provider's no-training and data-retention terms are reviewed for the provider in use (OpenAI or Anthropic), and schools are told that names go to the model (RISKS.md H-item). Money, deletions and safety steps are never done without the confirm tap; there is no "act on its own" mode.
