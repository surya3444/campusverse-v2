2. Scope node: where in the hierarchy . A group role sees all institutions below it; a
branch user sees only their branch.
3. Relationship: own sections, own mentees, own wards, own leads.
4. Data class: public, internal, personal, financial, or sensitive (health, counselling,
category and caste certificates).
Three rules sit on top:
Sensitive data is opt-in per role. Group owners and principals see health totals, never
names, unless granted for a case. Every such grant is logged.
Break-glass access exists for emergencies. It needs a reason, alerts the data
protection officer and expires.
Mitra inherits the same four checks. It can never answer with data the user could not
open themselves.
Institutions copy and edit any template. Changes are versioned and logged.
