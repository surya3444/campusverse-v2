# school/enrolment

Which section a student is in, and when. It implements people/records' `AcademicPlacementPort` as `schoolPlacement`.

| Function                   | Notes                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `enrol`                    | Inside the caller's transaction (used by setup imports)                                                                                                                                                                                                                                                                                                                     |
| `changeSection`            | Ends the old enrolment the day before and starts a new one; same class and year only, not into a closed section; history stays; the next roll number in the new section unless one is given. Refused with `attendance_taken` (and the days) when either register is taken on or after the start, so attendance is never split. Needs `school.enrolment.change` and a reason |
| `sectionOptions`           | For the Change section screen: the other sections of the class this year with headcount, seats, class teacher, the roll number the student would get, and the earliest start (today, or tomorrow if either register is taken today)                                                                                                                                         |
| `schoolPlacement`          | Current class, section and admission number for a person on a date; `getPlacements` answers for a whole list in one query; `findByReference` finds people by admission-number prefix (the fee counter's search)                                                                                                                                                             |
| `enrolledKeys`             | Students already enrolled in an institution (import duplicate checks)                                                                                                                                                                                                                                                                                                       |
| `removeImportedEnrolments` | Import undo                                                                                                                                                                                                                                                                                                                                                                 |

**Owned tables:** `school_enrolment` (created in migration 0004).

**Events:** `school.enrolment.section_changed.v1`.
